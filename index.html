Cara pasang

Sekali pasang. Setelah itu chat muncul otomatis setiap kali kamu live.

  1. Pasang Social Stream Ninja

    Install ekstensinya di Chrome, aktifkan, lalu buka pop-out chat YouTube atau TikTok Live.

  2. Ambil kode session

    Buka menu ekstensi. Salin teks setelah ?session= pada link overlay.

  3. Buat URL di atas

    Pilih template, tempel kode session, lalu tekan Salin URL.

  4. Tambahkan ke OBS

    Sources, tambah, Browser. Tempel URL, atur lebar 500 dan tinggi 800, lalu OK.
